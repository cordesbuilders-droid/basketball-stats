Game Stats works offline
Connecting…
Add this to your Home Screen to use it like an app. iPhone: open in Safari, tap Share, then Add to Home Screen. Android: in Chrome, tap the menu, then Add to Home screen. Saved games sync to every phone and computer that opens this link.

Enter team code

Anyone with the link can view stats. The team code lets this device save, edit, and delete games. You only enter it once on each device.
